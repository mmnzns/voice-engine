- **App-data folder.** Mac: `~/Library/Application Support/com.craftconceptsdigital.parlato/`. Windows: `%LOCALAPPDATA%\com.craftconceptsdigital.parlato\` (Local, not Roaming). All models live under it in `Models/`, `ParakeetModels/` and `LlmModels/`. Parlato's settings file there is `parla.settings.json`; the selected models are stored under `selected_whisper_model`, `selected_parakeet_model` and `llm_selected_gguf` (values are the ids above).
- **One layout everywhere.** Same folders and file names on Windows x64, Windows ARM64 and the Mac, and whether the graphics card (DirectML) or the processor runs the model. No other model folder exists, and Parlato has never moved models from an older folder.
- **Names that don't match.** Local AI files are named `(id).gguf`, not after the Hugging Face file: Granite is `granite-4.2-3b-q4.gguf` on disk but `granite-4.2-3b-Q4_K_M.gguf` in the repo; the four dropped models are the same (their repo files are `Qwen2.5-3B-Instruct-Q4_K_M.gguf`, `Llama-3.2-3B-Instruct-Q4_K_M.gguf`, `gemma-2-2b-it-Q4_K_M.gguf`, `Phi-3.5-mini-instruct-Q4_K_M.gguf`). Whisper files are `(id).bin` and the id keeps the `ggml-` prefix, so they match the repo names. Silero sits in `Models/` with Whisper but is not a Whisper model. Nemotron sits in `ParakeetModels/`. Parakeet Ultra and Nemotron come from subfolders in their repos but are stored flat. Unified and Nemotron use `tokenizer.model` / `encoder.onnx` / `decoder_joint.onnx`, while v2, v3 and Ultra use `vocab.txt` / `config.json` / `nemo128.onnx` / `encoder-model…` / `decoder_joint-model…`.
- **Imports are copies** inside Parlato's folder (`Models/imported/`, `LlmModels/imported/`), not links to the original path. Their id is `imported:` plus the file name without extension.
- **Half-downloaded files.** Single files keep a `.part` next to the target: `(name).bin.part`, `(name).gguf.part`. In Parakeet folders the last extension is replaced instead: `encoder-model.onnx.data` → `encoder-model.onnx.part`, `vocab.txt` → `vocab.part`, `encoder.int8.onnx` → `encoder.int8.part`. A Parakeet folder counts as downloaded only when every listed file is there.
- **Which local AI models are offered today.** Only Qwen 2.5 3B is already hidden in 0.14.1 (shown only if downloaded). Llama 3.2, Gemma 2 and Phi-3.5 are still downloadable in 0.14.1, so people can have any of the four on disk when the move runs.
