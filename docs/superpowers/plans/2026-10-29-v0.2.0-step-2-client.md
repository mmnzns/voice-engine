# v0.2.0 step 2: voice-engine-client implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new crate, `voice-engine-client`, is the app side of the local AI helper: it starts the helper, restarts it
when it dies (including at startup), speaks protocol 2 with it, turns every failure into one `EngineError` the app can
match on, stops a reply on request, and uses the Windows Vulkan helper first with a remembered fallback to the
processor helper.

**Architecture:** `process.rs` owns one helper process (spawn, a stdout reader thread, a stderr tail, a ping and
protocol check). `llm.rs` owns the policy: which helper, retries, timeouts, GPU memory, cancel. `gpu_memory.rs` is the
tiny file that remembers a GPU failure. A fake helper binary (`tests/fake_helper.rs`) speaks the protocol with
scripted failures so every behaviour is tested without a model.

**Tech Stack:** Rust 2024, std threads and channels (blocking API, safe to call from any worker thread),
`voice-engine-protocol`, serde_json, tempfile (tests).

**Spec:** `docs/superpowers/specs/2026-10-29-voice-engine-v0.2.0-design.md`, section 8. Step 2 of 8. The speech client
(`SttClient`) and `servers::detect()` from section 8 are built in steps 5 and 6, when the things they talk to exist.

**Why a client at all:** Talaan's `summarizer/local.rs`, `helper.rs` and `gpu.rs` (MIT) and Ensayo's copy of them are
the only code that starts the helper today; each app has its own. This crate is that code once, plus what the review
asked for: a helper that dies at startup is restarted (found on the Mac: several helpers starting at once can die with
SIGBUS inside Apple's Metal shader cache), an error says what happened (`EngineError`), and a GPU failure is
reported as "used the processor" instead of an error.

- Never read or copy code from Parlato. Talaan's and Ensayo's code (MIT) may be read for behaviour; this plan already

```rust
//! Every way a request to the helper can fail, as one type the app matches on (never on message text).

use voice_engine_protocol::ErrorKind;

#[derive(Debug, Clone, PartialEq)]
pub enum EngineError {
    /// The model file isn't where it should be.
    ModelMissing { path: String },
    /// Not enough memory for the model (the helper said so, or it died with an out-of-memory message).
    OutOfMemory,
    PromptTooLong {
        prompt_tokens: u32,
        n_ctx: u32,
        max_tokens: u32,
    },
    BadSchema { detail: String },
    NoChatTemplate,
    /// Stopped by the app (`LlmClient::cancel`).
    Cancelled,
    /// The graphics card failed and the processor could not finish the work either, or the helper was a processor
    /// helper that reported it.
    GpuFailed { fell_back: bool },
    BadRequest,
    Internal { message: String },
    /// The helper process died and trying again did not help.
    Crashed,
    /// The helper and the app were built against different protocol versions.
    VersionMismatch { helper: u32, app: u32 },
    /// No answer within the limits (the helper was stopped).
    TimedOut,
    /// The helper could not be started at all.
    CouldNotStart { message: String },
}

impl EngineError {
    /// The error a helper reported, as the app sees it.
    pub fn from_helper(error: ErrorKind, message: String) -> Self {
        match error {
            ErrorKind::ModelMissing { path } => EngineError::ModelMissing { path },
            ErrorKind::OutOfMemory => EngineError::OutOfMemory,
            ErrorKind::PromptTooLong {
                prompt_tokens,
                n_ctx,
                max_tokens,
            } => EngineError::PromptTooLong {
                prompt_tokens,
                n_ctx,
                max_tokens,
            },
            ErrorKind::BadSchema { detail } => EngineError::BadSchema { detail },
            ErrorKind::NoChatTemplate => EngineError::NoChatTemplate,
            ErrorKind::Cancelled => EngineError::Cancelled,
            ErrorKind::GpuFailed { fell_back } => EngineError::GpuFailed { fell_back },
            ErrorKind::BadRequest => EngineError::BadRequest,
            ErrorKind::Internal => EngineError::Internal { message },
        }
    }
}

impl std::fmt::Display for EngineError {
    /// For logs only. Apps show their own wording and match on the variant.
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "{self:?}")
    }
}

impl std::error::Error for EngineError {}
```

```rust
//! One helper process: spawn it, read its events on a thread, keep the tail of what it wrote to stderr (only to tell
//! "out of memory" apart when it dies; the tail is never logged or returned), and check it with a ping at startup.

use std::io::{BufRead, BufReader, Read, Write};
use std::path::Path;
use std::process::{Child, ChildStdin, Command, Stdio};
use std::sync::mpsc::{self, Receiver, RecvTimeoutError};
use std::sync::{Arc, Mutex};
use std::time::Duration;
use voice_engine_protocol::{Backend, Event, PROTOCOL_VERSION, Request, decode_event, encode};

/// What the stdout thread hands over.
enum Incoming {
    Event(Event),
    /// stdout closed: the helper exited.
    Closed,
}

pub(crate) enum Recv {
    Event(Event),
    Closed,
    Timeout,
}

#[derive(Debug, PartialEq)]
pub(crate) enum StartFailure {
    /// The executable couldn't be run (missing, no permission).
    CouldNotSpawn(String),
    /// The process ended before it answered the ping (on a Mac, a crash in Metal's shader cache can do this).
    Died,
    TimedOut,
    VersionMismatch { helper: u32 },
    /// It answered the ping with something other than `ready`.
    NotReady,
}

/// Enough of stderr's end to recognise an out-of-memory death.
const TAIL: usize = 4096;

pub(crate) struct Process {
    child: Child,
    stdin: Arc<Mutex<ChildStdin>>,
    incoming: Receiver<Incoming>,
    stderr_tail: Arc<Mutex<Vec<u8>>>,
}

impl Process {
    fn spawn(path: &Path, env: &[(String, String)]) -> Result<Process, String> {
        let mut cmd = Command::new(path);
        cmd.envs(env.iter().map(|(k, v)| (k.as_str(), v.as_str())))
            .stdin(Stdio::piped())
            .stdout(Stdio::piped())
            .stderr(Stdio::piped());
        // No console window flashing up on Windows.
        #[cfg(windows)]
        {
            use std::os::windows::process::CommandExt;
            cmd.creation_flags(0x0800_0000);
        }
        let mut child = cmd
            .spawn()
            .map_err(|e| format!("couldn't start {}: {e}", path.display()))?;
        let stdin = child.stdin.take().ok_or("no stdin")?;
        let stdout = child.stdout.take().ok_or("no stdout")?;
        let mut stderr = child.stderr.take().ok_or("no stderr")?;

        let (tx, incoming) = mpsc::channel();
        std::thread::spawn(move || {
            for line in BufReader::new(stdout).lines() {
                let Ok(line) = line else { break };
                // A line that isn't an event (a stray library message) is ignored.
                if let Ok(ev) = decode_event(&line)
                    && tx.send(Incoming::Event(ev)).is_err()
                {
                    return;
                }
            }
            let _ = tx.send(Incoming::Closed);
        });

        let stderr_tail = Arc::new(Mutex::new(Vec::new()));
        let tail = Arc::clone(&stderr_tail);
        std::thread::spawn(move || {
            let mut buf = [0u8; 1024];
            while let Ok(n) = stderr.read(&mut buf) {
                if n == 0 {
                    break;
                }
                let mut t = tail.lock().unwrap_or_else(|e| e.into_inner());
                t.extend_from_slice(&buf[..n]);
                if t.len() > TAIL {
                    let cut = t.len() - TAIL;
                    t.drain(..cut);
                }
            }
        });

        Ok(Process {
            child,
            stdin: Arc::new(Mutex::new(stdin)),
            incoming,
            stderr_tail,
        })
    }

    /// Starts the helper and checks it with a ping: it must answer `ready` with this build's protocol version.
    pub fn start(
        path: &Path,
        env: &[(String, String)],
        wait: Duration,
    ) -> Result<(Process, Backend), StartFailure> {
        let mut p = Process::spawn(path, env).map_err(StartFailure::CouldNotSpawn)?;
        if p.send(&Request::Ping).is_err() {
            p.kill();
            return Err(StartFailure::Died);
        }
        match p.recv(wait) {
            Recv::Event(Event::Ready { backend, protocol }) => {
                if protocol != PROTOCOL_VERSION {
                    p.kill();
                    Err(StartFailure::VersionMismatch { helper: protocol })
                } else {
                    Ok((p, backend))
                }
            }
            Recv::Event(_) => {
                p.kill();
                Err(StartFailure::NotReady)
            }
            Recv::Closed => {
                p.kill();
                Err(StartFailure::Died)
            }
            Recv::Timeout => {
                p.kill();
                Err(StartFailure::TimedOut)
            }
        }
    }

    pub fn send(&self, request: &Request) -> std::io::Result<()> {
        write_line(&self.stdin, &encode(request))
    }

    /// A handle another thread can use to send `cancel` while a request is running.
    pub fn stdin_handle(&self) -> Arc<Mutex<ChildStdin>> {
        Arc::clone(&self.stdin)
    }

    pub fn recv(&self, timeout: Duration) -> Recv {
        match self.incoming.recv_timeout(timeout) {
            Ok(Incoming::Event(ev)) => Recv::Event(ev),
            Ok(Incoming::Closed) | Err(RecvTimeoutError::Disconnected) => Recv::Closed,
            Err(RecvTimeoutError::Timeout) => Recv::Timeout,
        }
    }

    /// The helper's last words (stderr) say it ran out of memory.
    pub fn died_of_memory(&self) -> bool {
        let tail = self.stderr_tail.lock().unwrap_or_else(|e| e.into_inner());
        let text = String::from_utf8_lossy(&tail).to_ascii_lowercase();
        text.contains("out of memory") || text.contains("failed to allocate")
    }

    pub fn kill(&mut self) {
        let _ = self.child.kill();
        let _ = self.child.wait();
    }
}

impl Drop for Process {
    fn drop(&mut self) {
        self.kill();
    }
}

pub(crate) fn write_line(stdin: &Mutex<ChildStdin>, line: &str) -> std::io::Result<()> {
    let mut s = stdin.lock().unwrap_or_else(|e| e.into_inner());
    writeln!(s, "{line}")?;
    s.flush()
}
```

```rust
//! A fake AI helper for the client's tests. `FAKE_MODE` picks a behaviour, `FAKE_STATE` is a file it keeps a counter
//! in (so a mode can fail the first N times and then work).
//!
//! Modes: (default) answers everything; `die_at_start` exits at once without a word; `die_at_start_twice` does that
//! for the first two starts; `wrong_protocol` answers `ready` with protocol 1; `die_on_complete` exits after one
//! progress event; `die_on_first_complete` exits before answering the first `complete` (an idle exit just as the
//! request arrives); `oom` writes an out-of-memory message and dies on `complete`; `stall` never answers `complete`;
//! `slow` writes progress until it gets `cancel`, then answers `cancelled`; `ignore_cancel` writes progress forever;
//! `gpu_ok` reports a Vulkan GPU and works; `gpu_die` reports a GPU and dies on `complete`; `gpu_error` reports a GPU
//! and answers `complete` with the graphics card failed.

use std::io::{BufRead, Write};
use std::sync::mpsc;
use std::time::Duration;
use voice_engine_protocol::{
    Backend, ErrorKind, Event, Inspection, PROTOCOL_VERSION, Phase, Reply, Request, decode_request,
    encode,
};

fn send(ev: &Event) {
    let mut out = std::io::stdout().lock();
    let _ = writeln!(out, "{}", encode(ev));
    let _ = out.flush();
}

/// Reads the counter in `path`, writes it plus one, and returns what it was.
fn bump(path: &str) -> u32 {
    let n = std::fs::read_to_string(path)
        .ok()
        .and_then(|t| t.trim().parse().ok())
        .unwrap_or(0);
    let _ = std::fs::write(path, (n + 1).to_string());
    n
}

fn main() {
    let mode = std::env::var("FAKE_MODE").unwrap_or_default();
    let state = std::env::var("FAKE_STATE").unwrap_or_default();
    if mode == "die_at_start" || (mode == "die_at_start_twice" && bump(&state) < 2) {
        std::process::exit(138);
    }
    let backend = if mode.starts_with("gpu") {
        Backend {
            backend: "vulkan".into(),
            device: Some("Fake GPU".into()),
            vram_mb: 8000,
        }
    } else {
        Backend::cpu()
    };
    let protocol = if mode == "wrong_protocol" {
        1
    } else {
        PROTOCOL_VERSION
    };

    let (tx, rx) = mpsc::channel::<String>();
    std::thread::spawn(move || {
        for line in std::io::stdin().lock().lines() {
            let Ok(line) = line else { break };
            if tx.send(line).is_err() {
                break;
            }
        }
    });

    while let Ok(line) = rx.recv() {
        let Ok(request) = decode_request(&line) else {
            continue;
        };
        match request {
            Request::Ping => send(&Event::Ready {
                backend: backend.clone(),
                protocol,
            }),
            Request::Configure(c) => send(&Event::Configured {
                idle_secs: c.idle_secs,
            }),
            Request::Load(_) => send(&Event::Loaded {
                seconds: 0.5,
                n_ctx_train: 4096,
                backend: backend.clone(),
            }),
            Request::Unload => send(&Event::Unloaded),
            Request::Inspect(_) => send(&Event::Inspected(Inspection {
                has_chat_template: true,
                thinks: false,
                n_ctx_train: 4096,
                architecture: "fake".into(),
            })),
            Request::Embed(_) => send(&Event::Embedded {
                vectors: vec![vec![1.0]],
            }),
            Request::Cancel | Request::Devices => {}
            Request::Complete(_) => match mode.as_str() {
                "die_on_complete" | "gpu_die" => {
                    send(&Event::Progress {
                        phase: Phase::Loading,
                        done: 0,
                        total: 0,
                    });
                    std::process::exit(139);
                }
                "die_on_first_complete" => {
                    if bump(&state) == 0 {
                        std::process::exit(139);
                    }
                    answer();
                }
                "oom" => {
                    eprintln!("GGML_ASSERT: out of memory");
                    std::process::exit(137);
                }
                "stall" => loop {
                    std::thread::sleep(Duration::from_secs(60));
                },
                "slow" => loop {
                    send(&Event::Progress {
                        phase: Phase::Writing,
                        done: 1,
                        total: 0,
                    });
                    match rx.recv_timeout(Duration::from_millis(50)) {
                        Ok(l) if matches!(decode_request(&l), Ok(Request::Cancel)) => {
                            send(&Event::Error {
                                message: "stopped by request".into(),
                                error: ErrorKind::Cancelled,
                            });
                            break;
                        }
                        _ => {}
                    }
                },
                "ignore_cancel" => loop {
                    send(&Event::Progress {
                        phase: Phase::Writing,
                        done: 1,
                        total: 0,
                    });
                    std::thread::sleep(Duration::from_millis(50));
                },
                "gpu_error" => send(&Event::Error {
                    message: "the graphics card failed".into(),
                    error: ErrorKind::GpuFailed { fell_back: false },
                }),
                _ => answer(),
            },
        }
    }
}

fn answer() {
    send(&Event::Progress {
        phase: Phase::Writing,
        done: 1,
        total: 0,
    });
    send(&Event::Done(Reply {
        text: "hi".into(),
        prompt_tokens: 3,
        output_tokens: 1,
        seconds: 0.1,
        truncated: false,
        thinking_tokens: 0,
        load_seconds: 0.0,
        thinking_text: None,
    }));
}
```

```rust
//! The AI helper from the app's side. One `LlmClient` per app: it starts the helper on the first request, keeps it
//! while the app runs, restarts it when it dies, and turns every failure into an [`EngineError`].
//!
//! Calls block and are safe from any worker thread; one request runs at a time (the helper runs one at a time too).
//! `cancel` and `shutdown` may be called from another thread while a request runs.

use crate::error::EngineError;
use crate::gpu_memory;
use crate::process::{Process, Recv, StartFailure, write_line};
use std::path::PathBuf;
use std::process::ChildStdin;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant};
use voice_engine_protocol::{
    Backend, Completion, Configure, Embedding, ErrorKind, Event, Inspect, Inspection, Load,
    PROTOCOL_VERSION, Reply, Request, encode,
};

/// How long a helper that was asked to stop may keep going before it is killed.
const CANCEL_GRACE: Duration = Duration::from_secs(2);
/// A helper that dies at startup is started again this many times in all (Metal's shader cache can crash one when
/// several start at the same moment).
const START_TRIES: u32 = 3;
const START_RETRY_PAUSE: Duration = Duration::from_millis(300);
/// How often a waiting request looks at its limits and at `cancel`.
const POLL: Duration = Duration::from_millis(100);

#[derive(Debug, Clone)]
pub struct Limits {
    /// The helper must answer its first ping within this.
    pub start: Duration,
    /// No event at all for this long is a stall.
    pub stall: Duration,
    /// A whole request may take this long.
    pub total: Duration,
}

impl Default for Limits {
    fn default() -> Self {
        Limits {
            start: Duration::from_secs(60),
            stall: Duration::from_secs(120),
            total: Duration::from_secs(30 * 60),
        }
    }
}

#[derive(Debug, Clone)]
pub struct LlmConfig {
    /// The processor helper (every platform).
    pub cpu_helper: PathBuf,
    /// The Windows Vulkan helper; tried first when present, until it fails once.
    pub gpu_helper: Option<PathBuf>,
    /// Environment for both helpers (for example `TALAAN_GPU`).
    pub env: Vec<(String, String)>,
    /// Environment for the GPU helper only (for example `VK_LOADER_LAYERS_DISABLE=~implicit~`).
    pub gpu_env: Vec<(String, String)>,
    /// A file remembering that the graphics card failed, so it isn't tried again on every start.
    pub gpu_failures: Option<PathBuf>,
    /// What the failure is remembered for: the app version and the graphics driver, so an update or a new driver
    /// gets a fresh try.
    pub gpu_key: String,
    /// Seconds of idle before the helper exits; None: it runs while the app runs.
    pub idle_secs: Option<u64>,
    pub limits: Limits,

/// A successful call: the value, where it ran, and whether the graphics card failed during this call and the
/// processor did the work instead (the app says so once and stops asking for the card).
#[derive(Debug, Clone)]
pub struct Outcome<T> {
    pub value: T,
    pub backend: Backend,
    pub fell_back: bool,
}

#[derive(Debug, Clone, PartialEq)]
pub struct LoadInfo {
    /// Seconds the load took; 0 when the model was already loaded.
    pub seconds: f32,
    /// The longest context the model was trained for.
    pub n_ctx_train: u32,
}

struct Running {
    process: Process,
    backend: Backend,
    on_gpu: bool,
}

/// Why one attempt at a request ended without an answer.
enum Attempt {
    /// The helper process is gone. `answered`: it had sent at least one event for this request.
    Died { answered: bool },
    /// The helper said no, or a limit was hit. `kill`: the helper is in an unknown state and must be stopped.
    Failed { error: EngineError, kill: bool },
}

pub struct LlmClient {
    config: Mutex<LlmConfig>,
    /// Held for the whole of a request.
    running: Mutex<Option<Running>>,
    /// The running helper's stdin, so `cancel` can write to it while `running` is held by a request.
    live_stdin: Mutex<Option<Arc<Mutex<ChildStdin>>>>,
    /// When `cancel` was last asked for during the current request.
    cancel_asked: Mutex<Option<Instant>>,
    /// The graphics card failed in this process; never try it again until the app restarts.
    gpu_disabled: AtomicBool,
}

impl LlmClient {
    pub fn new(config: LlmConfig) -> Self {
        LlmClient {
            config: Mutex::new(config),
            running: Mutex::new(None),
            live_stdin: Mutex::new(None),
            cancel_asked: Mutex::new(None),
            gpu_disabled: AtomicBool::new(false),
        }
    }

    /// Loads a model now, so the next request doesn't wait. A different path replaces the loaded model.
    pub fn load(
        &self,
        model_path: &str,
        n_ctx: u32,
        gpu: bool,
        progress: &mut dyn FnMut(&Event),
    ) -> Result<Outcome<LoadInfo>, EngineError> {
        let request = Request::Load(Load {
            model_path: model_path.into(),
            n_ctx,
            gpu,
        });
        self.exchange(&request, progress, &|ev| match ev {
            Event::Loaded {
                seconds,
                n_ctx_train,
                ..
            } => Some(LoadInfo {
                seconds: *seconds,
                n_ctx_train: *n_ctx_train,
            }),
            _ => None,
        })
    }

    pub fn complete(
        &self,
        completion: Completion,
        progress: &mut dyn FnMut(&Event),
    ) -> Result<Outcome<Reply>, EngineError> {
        self.exchange(&Request::Complete(completion), progress, &|ev| match ev {
            Event::Done(reply) => Some(reply.clone()),
            _ => None,
        })
    }

    pub fn embed(&self, embedding: Embedding) -> Result<Outcome<Vec<Vec<f32>>>, EngineError> {
        self.exchange(&Request::Embed(embedding), &mut |_| {}, &|ev| match ev {
            Event::Embedded { vectors } => Some(vectors.clone()),
            _ => None,
        })
    }

    /// What a GGUF file says about itself (chat template, thinking, trained context), without loading it.
    pub fn inspect(&self, model_path: &str) -> Result<Inspection, EngineError> {
        let request = Request::Inspect(Inspect {
            model_path: model_path.into(),
        });
        self.exchange(&request, &mut |_| {}, &|ev| match ev {
            Event::Inspected(i) => Some(i.clone()),
            _ => None,
        })
        .map(|o| o.value)
    }

    /// Frees the loaded model's memory now. With no helper running there is nothing to free, and none is started.
    pub fn unload(&self) -> Result<(), EngineError> {
        if self.running.lock().unwrap_or_else(|e| e.into_inner()).is_none() {
            return Ok(());
        }
        self.exchange(&Request::Unload, &mut |_| {}, &|ev| match ev {
            Event::Unloaded => Some(()),
            _ => None,
        })
        .map(|_| ())
    }

    /// Changes how long the helper waits without a request before exiting (None: until the app exits), now and
    /// for every helper started later. Takes effect without a restart and without unloading the model.
    pub fn set_idle(&self, idle_secs: Option<u64>) -> Result<(), EngineError> {
        self.config.lock().unwrap_or_else(|e| e.into_inner()).idle_secs = idle_secs;
        if self.running.lock().unwrap_or_else(|e| e.into_inner()).is_none() {
            return Ok(());
        }
        let request = Request::Configure(Configure { idle_secs });
        self.exchange(&request, &mut |_| {}, &|ev| match ev {
            Event::Configured { .. } => Some(()),
            _ => None,
        })
        .map(|_| ())
    }

    /// Stops the helper now (the app is closing, or wants the memory back).
    pub fn shutdown(&self) {
        // Kill through the stdin handle's owner: take the process out of `running` when it is free; when a request
        // holds it, closing happens when that request ends.
        if let Ok(mut running) = self.running.try_lock()
            && let Some(mut r) = running.take()
        {
            r.process.kill();
        }
    }

    // --- the core -----------------------------------------------------------------------------------------------

    /// Sends `request` and waits for the event `pick` accepts, passing every other event to `progress`.
    fn exchange<T>(
        &self,
        request: &Request,
        progress: &mut dyn FnMut(&Event),
        pick: &dyn Fn(&Event) -> Option<T>,
    ) -> Result<Outcome<T>, EngineError> {
        let mut running = self.running.lock().unwrap_or_else(|e| e.into_inner());
        let mut fell_back = false;
        let mut retried = false;
        loop {
            if running.is_none() {
                *running = Some(self.start()?);
            }
            let r = running.as_mut().expect("started above");
            *self.live_stdin.lock().unwrap_or_else(|e| e.into_inner()) = Some(r.process.stdin_handle());
            *self.cancel_asked.lock().unwrap_or_else(|e| e.into_inner()) = None;
            let attempt = self.attempt(r, request, progress, pick);
            *self.live_stdin.lock().unwrap_or_else(|e| e.into_inner()) = None;
            match attempt {
                Ok(value) => {
                    return Ok(Outcome {
                        value,
                        backend: r.backend.clone(),
                        fell_back,
                    });
                }
                Err(Attempt::Died { answered }) => {
                    let mut dead = running.take().expect("running above");
                    let out_of_memory = dead.process.died_of_memory();
                    dead.process.kill();
                    if dead.on_gpu {
                        // The graphics card helper died: remember it and do the work on the processor.
                        self.gpu_failed();
                        fell_back = true;
                        continue;
                    }
                    if !answered && !retried {
                        // An idle exit that raced the request: a fresh helper answers it.
                        retried = true;
                        continue;
                    }
                    return Err(if out_of_memory {
                        EngineError::OutOfMemory
                    } else {
                        EngineError::Crashed
                    });
                }
                Err(Attempt::Failed { error, kill }) => {
                    if matches!(error, EngineError::GpuFailed { .. }) && r.on_gpu {
                        let mut dead = running.take().expect("running above");
                        dead.process.kill();
                        self.gpu_failed();
                        fell_back = true;
                        continue;
                    }
                    if kill && let Some(mut dead) = running.take() {
                        dead.process.kill();
                    }
                    return Err(error);
                }
            }
        }
    }

    /// One try at a request on the running helper.
    fn attempt<T>(
        &self,
        r: &mut Running,
        request: &Request,
        progress: &mut dyn FnMut(&Event),
        pick: &dyn Fn(&Event) -> Option<T>,
    ) -> Result<T, Attempt> {
        if r.process.send(request).is_err() {
            return Err(Attempt::Died { answered: false });
        }
        let limits = self.config.lock().unwrap_or_else(|e| e.into_inner()).limits.clone();
        let began = Instant::now();
        let mut last_event = Instant::now();
        let mut answered = false;
        loop {
            match r.process.recv(POLL) {
                Recv::Event(Event::Error { message, error }) => {
                    return Err(Attempt::Failed {
                        error: EngineError::from_helper(error, message),
                        kill: false,
                    });
                }
                Recv::Event(ev) => {
                    answered = true;
                    last_event = Instant::now();
                    match pick(&ev) {
                        Some(value) => return Ok(value),
                        None => progress(&ev),
                    }
                }
                Recv::Closed => return Err(Attempt::Died { answered }),
                Recv::Timeout => {
                    let asked = *self.cancel_asked.lock().unwrap_or_else(|e| e.into_inner());
                    if asked.is_some_and(|t| t.elapsed() > CANCEL_GRACE) {
                        // It was told to stop and didn't: stop it for good.
                        return Err(Attempt::Failed {
                            error: EngineError::Cancelled,
                            kill: true,
                        });
                    }
                    if last_event.elapsed() > limits.stall || began.elapsed() > limits.total {
                        return Err(Attempt::Failed {
                            error: EngineError::TimedOut,
                            kill: true,
                        });
                    }
                }
            }
        }
    }

    /// Starts a helper: the graphics card one first when there is one and it hasn't failed, else the processor one.
    fn start(&self) -> Result<Running, EngineError> {
        let cfg = self.config.lock().unwrap_or_else(|e| e.into_inner()).clone();
        if let Some(gpu_path) = &cfg.gpu_helper
            && !self.gpu_disabled.load(Ordering::Relaxed)
            && !gpu_memory::failed(cfg.gpu_failures.as_deref(), &cfg.gpu_key)
        {
            let env: Vec<_> = cfg.env.iter().chain(&cfg.gpu_env).cloned().collect();
            match start_with_retries(gpu_path, &env, &cfg) {
                Ok((process, backend)) => {
                    let on_gpu = backend.on_gpu();
                    return Ok(Running {
                        process,
                        backend,
                        on_gpu,
                    });
                }
                // A version mismatch is the app's problem, not the card's.
                Err(e @ EngineError::VersionMismatch { .. }) => return Err(e),
                Err(_) => self.gpu_failed(),
            }
        }
        let (process, backend) = start_with_retries(&cfg.cpu_helper, &cfg.env, &cfg)?;
        Ok(Running {
            process,
            backend,
            on_gpu: false,
        })
    }

    fn gpu_failed(&self) {
        self.gpu_disabled.store(true, Ordering::Relaxed);
        let cfg = self.config.lock().unwrap_or_else(|e| e.into_inner());
        gpu_memory::record(cfg.gpu_failures.as_deref(), &cfg.gpu_key);
    }

    // --- cancel --------------------------------------------------------------------------------------------------

    /// Asks the running request to stop. The helper keeps its model; the request ends with
    /// `EngineError::Cancelled`. A helper that doesn't stop within a couple of seconds is killed. Does nothing when
    /// no request is running.
    pub fn cancel(&self) {
        let stdin = self.live_stdin.lock().unwrap_or_else(|e| e.into_inner()).clone();
        let Some(stdin) = stdin else { return };
        *self.cancel_asked.lock().unwrap_or_else(|e| e.into_inner()) = Some(Instant::now());
        let _ = write_line(&stdin, &encode(&Request::Cancel));
    }
}

/// Starts the helper at `path` and tells it the idle policy. A helper that dies at startup is started again.
fn start_with_retries(
    path: &std::path::Path,
    env: &[(String, String)],
    cfg: &LlmConfig,
) -> Result<(Process, Backend), EngineError> {
    let mut last = StartFailure::Died;
    for attempt in 0..START_TRIES {
        if attempt > 0 {
            std::thread::sleep(START_RETRY_PAUSE);
        }
        match Process::start(path, env, cfg.limits.start) {
            Ok((process, backend)) => {
                let configure = Request::Configure(Configure {
                    idle_secs: cfg.idle_secs,
                });
                if process.send(&configure).is_err() {
                    last = StartFailure::Died;
                    continue;
                }
                // `configured` is the next event; anything else, or silence, means the helper isn't usable.
                match process.recv(cfg.limits.start) {
                    Recv::Event(Event::Configured { .. }) => return Ok((process, backend)),
                    _ => {
                        last = StartFailure::NotReady;
                        continue;
                    }
                }
            }
            Err(StartFailure::VersionMismatch { helper }) => {
                return Err(EngineError::VersionMismatch {
                    helper,
                    app: PROTOCOL_VERSION,
                });
            }
            // Retrying a helper that couldn't be spawned or never answered would only wait longer.
            Err(e @ (StartFailure::CouldNotSpawn(_) | StartFailure::TimedOut)) => {
                return Err(start_error(e));
            }
            Err(e) => last = e,
        }
    }
    Err(start_error(last))
}

fn start_error(failure: StartFailure) -> EngineError {
    EngineError::CouldNotStart {
        message: match failure {
            StartFailure::CouldNotSpawn(m) => m,
            StartFailure::Died => "the AI helper exited while starting".into(),
            StartFailure::TimedOut => "the AI helper did not answer in time".into(),
            StartFailure::VersionMismatch { .. } => "the AI helper is from another version".into(),
            StartFailure::NotReady => "the AI helper did not say it was ready".into(),
        },
    }
}
```

```rust
//! A small file that remembers "the graphics card failed" so the app doesn't try it again on every start. It holds
//! one line: the key of the build and driver that failed (the app picks it, for example "1.2.0 | driver 560.94").
//! A new build or a new driver has a different key and gets a fresh try. It holds nothing about the person.

use std::path::Path;

/// Did the card fail for this key?
pub(crate) fn failed(path: Option<&Path>, key: &str) -> bool {
    path.and_then(|p| std::fs::read_to_string(p).ok())
        .is_some_and(|text| text.trim() == key)
}

/// Remembers that the card failed for this key. Does nothing without a path.
pub(crate) fn record(path: Option<&Path>, key: &str) {
    let Some(path) = path else { return };
    if let Some(dir) = path.parent() {
        let _ = std::fs::create_dir_all(dir);
    }
    let _ = std::fs::write(path, key);
}

/// Forgets a remembered failure: the app's "try the graphics card again".
pub fn clear_gpu_failure(path: &Path) {
    let _ = std::fs::remove_file(path);
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn a_failure_is_remembered_for_its_key_only() {
        let dir = tempfile::tempdir().unwrap();
        let file = dir.path().join("sub").join("gpu.txt");
        assert!(!failed(Some(&file), "a"));
        record(Some(&file), "a");
        assert!(failed(Some(&file), "a"));
        assert!(!failed(Some(&file), "b"));
        clear_gpu_failure(&file);
        assert!(!failed(Some(&file), "a"));
    }

    #[test]
    fn without_a_path_nothing_is_remembered() {
        record(None, "a");
        assert!(!failed(None, "a"));
    }
}
```
