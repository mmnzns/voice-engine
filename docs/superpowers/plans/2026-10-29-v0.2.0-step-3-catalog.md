# v0.2.0 Step 3: Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One built-in catalog for every kind of model (speech, voice detection, speaker separation, search, local AI) with the fields every app shows, Parlato's extra variants and Granite 4.2 3B, every file pinned to a commit with size and sha256.

**Architecture:** `crates/models` keeps its crate. `catalog.rs` becomes the only catalog (`llm_catalog.rs` and the `VAD`, `DIARIZATION`, `SEARCH` statics go away; they become entries of one `CATALOG` slice). `EngineKind` becomes `Kind` with a `Vad` variant. New fields: `licence`, `gpu`, `english_only`, `keeps_fillers`, `chunk_secs`, `llm`. `reuse_dirs`, `apps.rs` and `store.rs` stay as they are (step 4 replaces them with the shared folder); only the type rename touches them.

**Tech Stack:** Rust (workspace, edition from `Cargo.toml`), Python 3 stdlib for `tools/verify-catalog.py` (already in the repo, run it with `python3 -I tools/verify-catalog.py`).

Spec: `docs/superpowers/specs/2026-10-29-voice-engine-v0.2.0-design.md` section 6. Notion page "Voice Apps Engine Sync", group "3. Catalog".

## Rules for every task

- Work on `main` in `~/Developer/voice-engine`, one commit per task, message ends with the attribution line you are given.
- Before each commit: `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`. All green.
- **Never invent a URL, size or hash.** Every value for a new file is in the data tables below, taken from Hugging Face's own listing on 2026-10-29. After any catalog edit run `python3 -I tools/verify-catalog.py`; it must print `N files checked, 0 problems`.
- Never read or copy Parlato's code. Everything needed from Parlato is in `docs/data/parlato-0.14.1-model-layout.md`.
- Notes in the catalog (`note:`) are plain sentences that name no app and no recommendation.
- Do not add Qwen 2.5 3B, Llama 3.2 3B, Gemma 2 2B or Phi-3.5 mini. They are dropped on purpose.

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum Kind {
    Whisper,
    Parakeet,
    ParakeetUnified,
    Nemotron,
    Vad,
    Diarization,
    Embedding,
    Llm,
}

impl Kind {
    /// A model that turns speech into text (the ones an app offers as speech models).
    pub fn is_speech(self) -> bool {
        matches!(self, Kind::Whisper | Kind::Parakeet | Kind::ParakeetUnified | Kind::Nemotron)
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Licence {
    pub spdx: &'static str,
    pub url: &'static str,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct GpuSupport {
    pub mac_metal: bool,
    pub windows_vulkan: bool,
    pub windows_directml: bool,
}

/// What an app shows for a local AI model. Context sizes are in tokens.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct LlmInfo {
    /// The longest context the model was trained for (read from the GGUF header).
    pub context_max: u32,
    /// The longest context that fits on a computer with 8 GB of memory, weights included (measured, Task 4).
    pub context_8gb: u32,
    /// The same for 16 GB.
    pub context_16gb: u32,
    /// Its chat template has a thinking step.
    pub thinks: bool,
}

pub mod licences {
    use super::Licence;
    pub const MIT: Licence = Licence { spdx: "MIT", url: "https://opensource.org/license/mit" };
    pub const APACHE_2: Licence = Licence { spdx: "Apache-2.0", url: "https://www.apache.org/licenses/LICENSE-2.0" };
    pub const CC_BY_4: Licence = Licence { spdx: "CC-BY-4.0", url: "https://creativecommons.org/licenses/by/4.0/" };
    pub const OPENMDW_1_1: Licence = Licence { spdx: "OpenMDW-1.1", url: "https://openmdw.ai/license/1-1/" };
}

pub mod gpu {
    use super::GpuSupport;
    pub const WHISPER_AND_LLM: GpuSupport = GpuSupport { mac_metal: true, windows_vulkan: true, windows_directml: false };
    pub const PARAKEET_TDT: GpuSupport = GpuSupport { mac_metal: false, windows_vulkan: false, windows_directml: true };
    pub const NONE: GpuSupport = GpuSupport { mac_metal: false, windows_vulkan: false, windows_directml: false };
}

#[derive(Debug)]
pub struct ModelInfo {
    pub id: &'static str,
    pub name: &'static str,
    pub maker: &'static str,
    /// Plain sentence, names no app, makes no recommendation.
    pub note: &'static str,
    pub kind: Kind,
    /// Shown by the app ("25 European languages").
    pub languages: &'static str,
    pub english_only: bool,
    /// 1..3, for the dots the app shows.
    pub speed: u8,
    pub accuracy: u8,
    pub licence: Licence,
    pub files: &'static [ModelFile],
    pub gpu: GpuSupport,
    /// Speech: whether it keeps "um" and "uh" when asked to. None until measured (spec 9.4).
    pub keeps_fillers: Option<bool>,
    /// Speech: the longest chunk to send (seconds). None: any length (Whisper).
    pub chunk_secs: Option<u32>,
    /// Local AI only.
    pub llm: Option<LlmInfo>,
    /// Folders, relative to another app's data folder, that may already hold these exact files (step 4 replaces
    /// this with the shared folder).
    pub reuse_dirs: &'static [&'static str],
}
```

Also add to `catalog.rs`:

```rust
impl ModelInfo {
    pub fn is_speech(&self) -> bool { self.kind.is_speech() }
}

/// Every model, speech first, in a stable order. Which one an app recommends is the app's business.
pub fn all() -> &'static [ModelInfo] { CATALOG }
pub fn speech() -> impl Iterator<Item = &'static ModelInfo> { CATALOG.iter().filter(|m| m.is_speech()) }
pub fn local_ai() -> impl Iterator<Item = &'static ModelInfo> { CATALOG.iter().filter(|m| m.kind == Kind::Llm) }
pub fn find(id: &str) -> Option<&'static ModelInfo> { CATALOG.iter().find(|m| m.id == id) }
```

#[test]
fn every_entry_has_the_fields_the_apps_show() {
    for m in all() {
        assert!(!m.name.is_empty() && !m.maker.is_empty() && !m.languages.is_empty() || m.kind == Kind::Vad, "{}", m.id);
        assert!(!m.licence.spdx.is_empty() && m.licence.url.starts_with("https://"), "{}", m.id);
        assert!((1..=3).contains(&m.speed) && (1..=3).contains(&m.accuracy), "{}", m.id);
        assert!(!m.files.is_empty(), "{}", m.id);
        for f in m.files {
            assert_eq!(f.sha256.len(), 64, "{}", f.name);
            assert!(f.sha256.chars().all(|c| c.is_ascii_hexdigit() && !c.is_ascii_uppercase()), "{}", f.name);
            assert!(f.size > 0, "{}", f.name);
            assert!(f.url.ends_with(f.name) || f.url.ends_with(&format!("/{}", f.name)), "{}", f.url);
            let (_, rest) = f.url.split_once("/resolve/").expect("hugging face resolve url");
            let rev = rest.split('/').next().unwrap();
            assert!(rev.len() == 40 && rev.chars().all(|c| c.is_ascii_hexdigit()), "{} is not pinned to a commit", f.url);
        }
    }
}
