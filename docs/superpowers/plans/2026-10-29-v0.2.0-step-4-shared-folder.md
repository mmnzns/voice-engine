# v0.2.0 Step 4: Shared Folder, Downloader, One-Time Move Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One model folder for the three apps (`Craft Concepts Digital/Models`), one downloader, "what is on this computer", delete-by-last-user, and a one-time move of each app's old models into it, so nothing is downloaded twice.

**Architecture:** All in `crates/models`. New modules: `download.rs` (blocking reqwest downloader), `shared.rs` (`SharedStore`: layout, users, locks, status, download, release, collect), `legacy.rs` (replaces `apps.rs`: every app's old folders and Parlato's name table), `moving.rs` (`move_in`), `imports.rs` (imported GGUF ids). `store.rs` (`ModelStore`, the v0.1.0 finder) and `ModelInfo::reuse_dirs` are removed at the end.

**Tech Stack:** Rust 2024, `reqwest` 0.12 (blocking, rustls, no default features), `sha2` 0.10, `std::fs::File::{lock, lock_shared, try_lock, try_lock_shared}` (stable), `tempfile` for tests. A tiny HTTP server written with `std::net::TcpListener` in the tests (no new dev-dependency).

Spec: `docs/superpowers/specs/2026-10-29-voice-engine-v0.2.0-design.md` sections 5.1 to 5.6 and 11 (this plan implements them; where the spec and this plan differ, this plan wins and says why). Notion group "4. Shared folder and downloader".

Changes from Talaan's:

```rust
pub struct Progress { pub fraction: f32, pub bytes: u64, pub total: u64 }   // over the whole model, every file together

#[derive(Debug)]
pub enum DownloadError {
    Offline,                  // no connection or DNS
    Refused { status: u16 },  // 4xx/5xx, or an HTML page (status = the HTTP status)
    DiskFull,
    Checksum { file: String },// size or sha256 mismatch; the bad file is deleted
    Stalled,                  // 30 s (configurable in tests) without data; .part kept
    Cancelled,                // .part kept
    Io(String),               // any other io error, message has no file contents
}
impl DownloadError { pub fn is_failure(&self) -> bool /* false for Cancelled and Stalled */ }

pub fn download_files(files: &[ModelFile], dir: &Path, cancel: &AtomicBool, idle: Duration,
                      progress: &mut dyn FnMut(Progress)) -> Result<(), DownloadError>;
pub fn partial_bytes(files: &[ModelFile], dir: &Path) -> u64;         // bytes already on disk: finished files + .part sizes
pub fn mark_cancelled(dir: &Path); pub fn clear_cancelled(dir: &Path); pub fn was_cancelled(dir: &Path) -> bool; // `.cancelled` marker file in dir
```

`download_files` skips a file that is already complete (exact size), starts `progress` at the bytes already there,
and reports `bytes`/`total` over the sum of all file sizes. It clears `.cancelled` when it starts and writes it when
cancelled. Disk full is `io::ErrorKind::StorageFull` (or raw OS errors 28 on Unix, 112 on Windows). A connection
error maps to `Offline` only for connect/DNS errors, otherwise `Io`. `ModelFile` has `&'static str` fields; tests
build files with `Box::leak` strings pointing at the local server.

## Task 2: `SharedStore` (`shared.rs`)

**Files:** Create `crates/models/src/shared.rs`; modify `lib.rs`. Keep `apps.rs` and `store.rs` untouched for now.

Layout (spec 5.2) exactly, under the store root:

```
<root>/<model id>/<files>      <root>/<model id>/<file>.part     <root>/<model id>/.cancelled
<root>/.engine/users/<model id>/<app>     (empty file; app = "talaan" | "ensayo" | "parlato")
<root>/.engine/locks/<model id>.use  <root>/.engine/locks/<model id>.download
<root>/.engine/moved/<app>
```

API (the spec's `open(id)` is named `hold(id)` here because `SharedStore::open(app)` is the constructor):

```rust
pub enum Status {
    Installed { dir: PathBuf, users: Vec<App>, used_by_me: bool },
    Downloading { fraction: f32, bytes: u64, by_me: bool },
    Partial { fraction: f32, bytes: u64, cancelled: bool },
    Missing,
}
pub enum Released { Erased, Kept { users: Vec<App> }, NotUsing }
pub enum StoreError { UnknownModel(String), DownloadingElsewhere, Download(DownloadError), Io(String) }

impl SharedStore {
    pub fn open(app: App) -> io::Result<Self>;                 // default folder (below); VOICE_ENGINE_MODELS_DIR, if set, is treated exactly like open_at
    pub fn open_at(app: App, dir: PathBuf) -> io::Result<Self>; // creates dir/.engine; `move_in` is a no-op returning MoveReport::skipped()
    pub fn default_dir() -> Option<PathBuf>;                    // Mac: <Application Support>/Craft Concepts Digital/Models; Windows: %LOCALAPPDATA%\Craft Concepts Digital\Models (dirs::data_local_dir()/"Craft Concepts Digital"/"Models")
    pub fn root(&self) -> &Path;
    pub fn model_dir(&self, id: &str) -> PathBuf;
    pub fn status(&self, id: &str) -> Status;
    pub fn list(&self) -> Vec<(&'static ModelInfo, Status)>;    // every catalog model, in catalog order ("what is on this computer")
    pub fn use_model(&self, id: &str) -> Result<(), StoreError>; // writes users/<id>/<app>
    pub fn download(&self, id: &str, cancel: &AtomicBool, progress: &mut dyn FnMut(Progress)) -> Result<PathBuf, StoreError>;
    pub fn hold(&self, id: &str) -> Result<ModelHandle, StoreError>; // shared lock on locks/<id>.use while alive; Err if not Installed
    pub fn release(&self, id: &str) -> io::Result<Released>;
    pub fn release_all(&self) -> io::Result<()>;
    pub fn collect(&self) -> io::Result<()>;
}
```

Behaviour (spec 5.3 is the contract; the points that need care):

- `status`: `Installed` when every catalog file is present with its exact size (hashes are checked at download). `Downloading` when the `.download` lock is held by someone (probe with `try_lock`; if the probe gets the lock, release it at once); `by_me` is true when this `SharedStore` instance holds it (keep an in-process set). `Partial` when `.part` files or some complete files exist but not all; `cancelled` is `was_cancelled(dir)`. Unknown id -> `Missing`.
- `download`: unknown id -> `UnknownModel`; writes the user marker first; `try_lock` exclusive on `.download`, if it fails -> `DownloadingElsewhere` (the app then shows the other app's progress from `status`); runs `download_files` into `model_dir(id)`; returns the directory. `Cancelled` and `Stalled` come back as `StoreError::Download(..)` (callers use `is_failure`).
- `hold`: opens `locks/<id>.use` and `lock_shared`; `ModelHandle` keeps the `File` and exposes `dir()`; dropping it releases the lock.
- `release(id)`: removes this app's user marker (`NotUsing` if there was none and the model has other users or none... see test list). If no users remain: `try_lock` exclusive on `.use`; if obtained, re-read the users under the lock and, if still none, erase `<id>/` and the marker directory and return `Erased`; if another app holds the model open, return `Kept` with the remaining users empty and leave the folder for `collect`. If other apps remain as users return `Kept { users }`.
- `release_all`: `release` for every model this app uses.
- `collect`: erase model folders with no users and no `.use` lock holder (use the same try_lock-then-recheck), and `.part` files older than 7 days with no `.download` lock. Never touches anything outside `<root>`.
- Everything is safe if two `SharedStore`s (two "apps") share one root in the same test process: locks are OS file locks on separately opened `File`s, so they conflict across instances (on Unix `flock` locks conflict between separate open file descriptions in one process; the tests prove it on this platform).

`moving.rs`:

```rust
pub struct MoveReport {
    pub moved: Vec<String>,        // ids moved in from this app's own old folders
    pub linked: Vec<String>,       // ids hard-linked in from other apps' folders
    pub imported: Vec<ImportedGguf>, // dropped Parlato GGUFs registered as imports (path + id), Parlato only
    pub left_for_later: Vec<(String, String)>, // (id, reason: "in use" | "hash mismatch" | "link failed")
    pub already_done: bool,
}
pub struct ImportedGguf { pub path: PathBuf, pub id: String }   // id from imports::import_id (Task 4)
impl SharedStore { pub fn move_in(&self, used: &[&str]) -> io::Result<MoveReport>; }
```

Rules, in order (spec 5.4 is authoritative; restated so nothing is missed):

1. `open_at` stores: return `already_done: true`, touch nothing. If `moved/<app>` exists: `already_done: true`.
2. Own old folders (all sources of this app, Talaan's Windows pair included). For each entry complete there (every catalog file present with exact size; for `verify_hashes` entries also sha256 equal to the catalog's, a mismatch means "hash mismatch" in `left_for_later` and the model is treated as absent):
   - not in the shared folder: `rename` each file into `<id>/` (create it), then hard-link the new file back at the old path; failure to link is ignored for own files (the old path stays empty). Mark this app a user.
   - already in the shared folder with the same size: delete the old copy, then hard-link the shared file back at the old path; mark user.
   - a model complete in both of Talaan's two Windows folders is moved once and the other copy is replaced by a link.
   - a file that is locked or open (try to open it for write; on failure, or when `std::fs::rename` fails with a sharing violation) is left alone, reported as `"in use"`, and the marker `moved/<app>` is **not** written, so the next start finishes the job.
3. Other apps' old folders: for each model complete there and missing from the shared folder, hard-link (never move) its files into `<id>/` and write that other app's user marker; a failed link is skipped silently (reported as `"link failed"`). Parlato entries from other apps are linked with their renamed file names. A model already shared just gets that app's marker.
4. Mark this app a user of every id in `used`.
5. Parlato only: any `LlmModels/*.gguf` that is not a table entry is registered (not moved, not copied, never deleted) in `ImportedGguf` with `import_id`.
6. Write `moved/<app>` last. Running again after an interruption (simulate by running `move_in` on a state where half the files are already renamed) finishes correctly and changes nothing that is done.
