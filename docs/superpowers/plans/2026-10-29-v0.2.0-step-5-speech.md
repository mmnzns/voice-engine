# v0.2.0 Step 5: Speech Runtimes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The engine transcribes one piece of audio with a loaded model and returns the segments and the timed words (`Transcript`), for Whisper (Metal on the Mac, Vulkan helper on Windows), Parakeet, Parakeet Unified and Nemotron (ONNX Runtime, DirectML on Windows), plus voice detection and speaker separation, all from MIT code and upstream sources.

**Architecture:** `crates/stt` keeps its name and gains modules: `api` (types and errors, spec 9.1), `threads` (the thread rule), `whisper_engine` (Whisper in process), `vad` (Silero through whisper.cpp), `parakeet_engine` (parakeet-rs), `diarize` (Sortformer). The existing helper (`run_helper`, `transcribe`, protocol `stt`) keeps working until Task 5 moves it onto the new API. `crates/client` gains `SttClient` (Task 5). The stt crate never depends on `voice-engine-llm` (no llama.cpp in it): a test asserts it.

**Tech Stack:** whisper-rs 0.16.0 (`metal` on macOS, `vulkan` feature for the Windows helper), parakeet-rs 0.3.8 (`sortformer`) with `ort =2.0.0-rc.13` (`default-features = false`, the pair both apps link; `directml` feature behind a crate feature, Windows only), Rust 2024.

Spec: `docs/superpowers/specs/2026-10-29-voice-engine-v0.2.0-design.md` section 9 (read it all first; it is the contract). Notion group "2. Speech runtimes".

## Task 1: API types, threads, Whisper in process

**Files:** Create `crates/stt/src/api.rs`, `threads.rs`, `whisper_engine.rs`; modify `lib.rs` (re-exports; keep `is_noise`, `transcribe`, `run_helper` as they are), `Cargo.toml` (`whisper-rs` gets the `metal` feature on macOS through `[target.'cfg(target_os = "macos")'.dependencies]`), `crates/stt/tests/`.

- [ ] **Step 1: `api.rs`** exactly the types in spec 9.1 (`LoadOptions`, `ChunkOptions`, `Timing`, `Transcript`, `Segment`, `Word`, `SpeechBackend`, trait `Transcriber`), plus `SpeechError` (a kind, never text matching: `ModelMissing`, `BadModel`, `OutOfMemory`, `Unsupported(String)`, `Internal(String)`; `Display` without audio or text), `ChunkOptions::default()` (`language: None`, `timing: Timing::Words`, `keep_fillers: false`, `vocabulary: vec![]`), and `load(model: &ModelInfo, dir: &Path, opts: LoadOptions) -> Result<Box<dyn Transcriber>, SpeechError>` dispatching on `model.kind` (Whisper now; the ONNX kinds return `Unsupported` until Task 3).
- [ ] **Step 2: `threads.rs`** the rule of spec 9.2: `default_threads(kind: ThreadKind /* Processor | Gpu */, logical: usize) -> usize`: processor: three quarters of the logical cores clamped 2..=12 on every system; GPU (Metal, Vulkan, DirectML): all cores clamped 2..=8. Keep the old `thread_count`/`threads` functions working (the helper uses them) and mark them `#[deprecated]` only if clippy stays clean. Tests: tables for 4, 8, 10, 12, 16, 32 logical cores both kinds; `LoadOptions::threads = Some(n)` wins (n clamped to at least 1).
- [ ] **Step 3: `whisper_engine.rs`**, a `Transcriber` for Whisper models:
  - loading: `gpu: true` uses Metal on macOS (flash attention as Talaan does) or Vulkan when built with the `vulkan` feature; if the device fails to load the model, load on the processor and report `backend().fell_back == true` with `backend` `"cpu"`. `device` names the GPU when known.
  - `Timing::Segments`: exactly Talaan's settings today. `Timing::Words`: exactly Ensayo's (token timestamps, split on word, one word per segment, then Ensayo's `words::clean`). Every result carries `segments` with their `words` in BOTH modes (in Segments mode derive words from the token timestamps without changing the segments' text and times).
  - any length in one call (whisper.cpp windows internally); audio shorter than 1 s is padded with silence to 1 s (never an error); word and segment times are clamped to the real audio length.
  - `vocabulary`: the words joined with ", " become whisper.cpp's initial prompt (empty list: no prompt). `keep_fillers: true` adds the filler prompt whisper.cpp's docs describe ("Umm, let me think like, hmm... Okay, here's what I'm, like, thinking."); it composes with `vocabulary` (fillers prompt first, then the words).
  - `language: Some("fr")` passes as is; `None` detects; `Transcript.language` is what Whisper settled on.
  - early stop: when decoding ended with 2 s or more of audio left after the last word, resume on the remaining audio as Ensayo does, concatenating results with the right offsets, and set `stopped_early_at_ms` to where the first stop happened.
  - threads: `LoadOptions.threads` or the Task 1 default for the backend that actually loaded.
- [ ] **Step 4: Tests (CI, synthetic)** in `crates/stt/tests/whisper_api.rs`: pure-function tests for everything that does not need a model: padding of a 0.4 s clip to 1 s, time clamping, prompt building (vocabulary only, fillers only, both, neither), early-stop offset arithmetic, `words::clean` cases ported from Ensayo's tests, thread defaults. If a tiny Whisper model can be built in CI cheaply do not bother; the real model test below covers the engine.
- [ ] **Step 5: Real-model tests (`#[ignore]`)** in `crates/stt/tests/real_whisper.rs`, with `whisper-turbo` from the Talaan folder and a clip you generate: a 3 s clip, and the same speech text rendered as audio by the macOS `say -o clip.aiff` command converted to 16 kHz mono f32 (use `afconvert`, or write the conversion in the test with the standard library); assertions: words present and ordered with `start_ms <= end_ms`, segments text non-empty, both modes give both segments and words, a 0.4 s clip works, a 3-minute clip (concatenate the speech clip) runs in one call, `vocabulary: ["Zorblax"]` is accepted, `backend().backend == "metal"` with `gpu: true` and `"cpu"` with `gpu: false`, `threads: Some(3)` is honoured (assert through the reported thread count if available, otherwise through a debug accessor on the engine). Run them with `cargo test -p voice-engine-stt -- --ignored` and paste the output in your report.
- [ ] **Step 6:** fmt, clippy, tests. **Step 7: Commit** `stt: Transcript API, thread rule, Whisper in process with Metal, both timing modes`.

## Task 3: Parakeet, Parakeet Unified and Nemotron (`parakeet_engine.rs`)

- [ ] Port from Talaan `transcriber/engine.rs` and Ensayo `speech/engine.rs`: 0.5 s of silence on each side of the chunk, up to 8 resume passes when decoding stops early (set `stopped_early_at_ms` like Whisper), `Timing::Segments` uses parakeet-rs sentence timestamps (Talaan), `Timing::Words` its word timestamps (Ensayo), both modes return segments and words, chunks up to `chunk_secs` (40 s; longer input is an `Unsupported`-free split? ## Task 5: The helper on the new API, and `SttClient`

**Files:** Modify `crates/protocol/src/stt.rs`, `crates/protocol/src/lib.rs` (only if the version constant needs it), `crates/stt/src/helper.rs`, `crates/stt/src/main.rs`; create `crates/client/src/stt.rs`, `crates/client/src/bin/fake_stt_helper.rs`, `crates/client/tests/stt_client.rs`; modify `crates/client/src/lib.rs`, `crates/client/Cargo.toml`.

- [ ] Protocol `stt` module: requests `Load { model_dir, kind, gpu, threads }`, `Transcribe { audio_b64 | audio path, options }` with the new `ChunkOptions` fields (language, timing, keep_fillers, vocabulary), `Unload`, `Ping`; events `Loaded { seconds, backend }`, `Transcribed(Transcript with segments and words)`, `Unloaded`, `Error { kind }`. `PROTOCOL_VERSION` stays 2 (nothing shipped yet on protocol 2 for speech; the v0.1.0 stt messages are replaced, noted in the CHANGELOG as a breaking change for anyone who adopted v0.1.0, nobody did). Round-trip tests for every message; old v0.1.0 messages are not supported (document).

- [ ] `SttClient` mirrors `LlmClient`: starts the helper (3 startup tries, protocol check), `load`, `transcribe`, `unload`, `shutdown`, GPU helper first with remembered fallback (`fell_back` in the result), every failure an `EngineError`/`SpeechError` kind, limits (`start`, `stall`, `total`) checked on every loop pass, cancel with the grace period. Reuse `process.rs` and `gpu_memory.rs`; do not copy them.
- [ ] Tests: a `fake-stt-helper` binary with scripted behaviour (like the fake LLM helper) and tests for: normal transcribe, helper dying mid-call, protocol version mismatch, idle/unload, stall and total limits with a helper that keeps streaming, GPU failure remembered, cancel. A process test of the real helper binary with `Ping`/`Load` of a missing model (kind `ModelMissing`). An `#[ignore]` real test: `SttClient` + real helper + `whisper-turbo` + a `say` clip.
