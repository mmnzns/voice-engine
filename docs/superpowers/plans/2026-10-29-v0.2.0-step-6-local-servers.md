# v0.2.0 Step 6: Local AI Servers (Ollama, LM Studio) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `servers::detect()` in `voice-engine-client` says which local AI servers are running on this computer (Ollama on port 11434, LM Studio on port 1234) and lists each one's models with name and context size. The apps keep making the chat requests to those servers themselves (they are OpenAI-compatible); the engine only detects and lists.

**Architecture:** One module `crates/client/src/servers.rs`, blocking `reqwest` (add it to the client crate; the workspace already has it), short timeouts (connect 300 ms, total 2 s per server so an app can call it on a settings screen), no retries, no background threads. Ollama: `GET /api/tags` for the model list, `POST /api/show` with `{"model": name}` per model for the context length (`model_info["<architecture>.context_length"]`). LM Studio: `GET /api/v0/models` (its native listing, which has `max_context_length` and `type`; keep only `type` values `llm` and `vlm`, drop `embeddings`). The GGUF `inspect` request (step 1) and its client method (step 2) already cover imported GGUF files; nothing to do for them here.

**Spec:** section 8 of `docs/superpowers/specs/2026-10-29-voice-engine-v0.2.0-design.md` (the `servers::detect()` bullet). Notion group "3. Catalog", item "Ollama and LM Studio".

## Task 1: `servers::detect`

**Files:** Create `crates/client/src/servers.rs`, `crates/client/tests/servers.rs`; modify `crates/client/src/lib.rs`, `crates/client/Cargo.toml`, `README.md`, `CHANGELOG.md`, `SOURCES.md`.

```rust
pub enum ServerKind { Ollama, LmStudio }
pub enum ServerState { Running, Unreadable }
pub struct ServerModel {
    pub id: String,                       // what the app puts in the request's "model" field
    pub context_length: Option<u32>,      // the model's limit, None when the server does not say
    pub size_bytes: Option<u64>,          // when the server says
}
pub struct LocalServer {
    pub kind: ServerKind,
    pub base_url: String,                 // "http://localhost:11434", no "/v1"
    pub api_base: String,                 // base_url + "/v1": the OpenAI-compatible root the apps send chat requests to
    pub state: ServerState,
    pub models: Vec<ServerModel>,         // empty when Unreadable
}
pub struct Probe { pub kind: ServerKind, pub base_url: String }
pub fn detect() -> Vec<LocalServer>;                 // default probes: Ollama http://127.0.0.1:11434, LM Studio http://127.0.0.1:1234
pub fn detect_at(probes: &[Probe]) -> Vec<LocalServer>;
```
