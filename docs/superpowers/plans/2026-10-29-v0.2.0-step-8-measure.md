**Goal:** Numbers on real models on this Mac (an M3 Pro, 18 GB) for the bars the apps asked for, the per-model fillers flag measured, the downloader proved once against the real Hugging Face, and the ignored real-model suites run and recorded. Then docs and the tag (the controller does the tag).

**Notion items:** group 1 "Speed numbers for a 50-words-in, 50-out cleanup with Qwen 3.5 4B and Granite 4.2 3B"; group 2 "Speed bar" ("Whisper Large v3 Turbo about 25x real time on Metal; Parakeet Ultra about 50x on a Windows processor"), "Speech speed floor for Parlato" (M3 Pro, 29 s of audio, processor: Whisper Base about 0.50 s, Parakeet Ultra about 0.43 s), "fillers kept, with a per-model flag". Spec sections 9.4 and 9.5.

## Rules

- Work on `main` in `~/Developer/voice-engine`, commits end with the attribution line you are given. Do not push.
- Models on this Mac: Talaan's folder `~/Library/Application Support/Talaan/models/<id>/` (read-only: `whisper-turbo`, `parakeet-ultra`, `vad`, `diarization`, `search`) and the shared folder `~/Library/Application Support/Craft Concepts Digital/Models/<id>/` (`qwen3.5-4b`, `qwen3.5-9b`, `granite-4.2-3b`; you may add models there through the engine's own downloader). Never delete or modify anything in Talaan's folder, Ensayo's or Parlato's; never delete anything in the shared folder.
- Measurements must say how they were taken: release build, number of runs (3 after one warm-up, report the median and the range), thread counts, backend (`metal` or `cpu`), audio length. Close other heavy programs is not possible: report the load if you notice one (`uptime`).
- Audio: build a 29 s clip by concatenating `say` renders (several sentences, 16 kHz mono f32), the same way `crates/stt/tests/common/mod.rs` does. Real-time factor = audio seconds / decode seconds (so 25x means 25 times faster than real time).
- Nothing the person said in logs: the bench prints sizes, times and counts only, never the transcript or the prompts.

## Task 2: Fillers, measured (spec 9.4)

**Files:** Modify `crates/models/src/catalog.rs` (the `keeps_fillers` of `whisper-turbo` and `parakeet-ultra`, nothing else), `crates/stt/tests/real_fillers.rs` (new, `#[ignore]`), docs.

- [ ] A test recording with fillers: build it with `say` from sentences that contain spoken "um" and "uh" and "like" ("So, um, I think, uh, we should, like, start on Monday."), 6 sentences, at least two voices. For each of `whisper-turbo` and `parakeet-ultra` transcribe it in four ways: `keep_fillers` false and true, in Words mode. Count how many of the spoken fillers (case-insensitive tokens `um`, `umm`, `uh`, `uhh`, `like`, `hmm`) appear in the transcript in each case, and report the four counts per model next to the number spoken.
- [ ] Rule for the catalog flag: `keeps_fillers = Some(true)` when with `keep_fillers: true` at least 80% of the spoken fillers appear and that is more than without the option (or the model keeps them either way); `Some(false)` when fewer than 80% appear even with the option; `None` stays for models that could not be measured here. Report the numbers; the controller decides if a result looks like a test artifact of text-to-speech voices (say so if TTS fillers sound unlike real ones). Set the two flags accordingly, update the catalog test that expects `None` everywhere, and put the measured table in `docs/bench-2026-10-29.md`.
